## 1. Experience goal
ผู้เล่นใช้เวลา 20–30 นาทีในรองเท้าของ Phineas เด็กที่ "เป็น 0" ในโลกที่ทุกคนมีเวท — หนาวเหน็บจากสายตาชาวบ้าน แต่อุ่นใจเพราะกำลังจะไปหาเอเลนา
แล้วในวินาทีที่เขาเสียสละที่สุด พลังต้องห้ามตื่นขึ้น และคนเดียวที่เขามีกลับมองเขาเป็นสัตว์ประหลาด
**ผู้เล่นต้องออกจากเดโมด้วยความรู้สึก "เห็นใจ Phineas" และ/หรือ "ช็อกตอนเอเลนาปัดมือ"** (`06` เกณฑ์ข้อ 3)

Pillars ที่ใช้ในเดโม (`01` §3): **อารมณ์นำเกม** · **พลังมีราคา** (เห็นผ่านความเจ็บปวด/Humanity ที่ซ่อนอยู่) · **แมพเล็กแต่แน่น** · **ปริศนาพ่อ** (ห้อง + ข้อความสุดท้าย)
Pillar "ต่อสู้มันและอ่านง่าย" → **ไม่อยู่ในเดโม** (D-001: combat ไปที่ P4)

### SC-02 — หมู่บ้านแห่งความเกลียดชัง `[CANON]` · 5–7 นาที
- **Beat:** เดินถือถังผ่านใจกลางหมู่บ้าน ชาวบ้านรังเกียจ แต่ในใจ Phineas ไม่สน เพราะกำลังจะไปหาเอเลนา
- `[IMPL]` **Ambient barks** แบบ 3D spatial (กระซิบเมื่อเดินผ่าน), เด็กหันหลัง, ประตูถูกปิด, ร้านค้าไม่ตอบ
- `[IMPL]` **Internal monologue** (ซับ) อบอุ่น ตัดกับความเย็นของชาวบ้าน
- `[IMPL]` Post-processing: โทนเย็น → อุ่นขึ้นเมื่อ monologue พูดถึงเอเลนา
- `[OWNER D-016]` **ไม่มีชาวบ้านคนไหนใจดีกับ Phineas ในเดโม** — เอเลนาต้องเป็นคนแรกที่ไม่เกลียดเขา; ชาวบ้านที่ "ไม่ได้เกลียดเต็มที่" เลื่อนไปหลังเดโม (หลังเอเลนาปฏิเสธ จะมีน้ำหนักกว่า)
- Layout (ฟ้าใส): เส้นทางหลักเส้นเดียวแต่มีซอยแยก 2–3 จุดให้ "รู้สึกสำรวจ" + Landmark = ต้นไม้ใหญ่ทางเข้าป่าที่มองเห็นตั้งแต่ลานกลาง; POI ทุก 30–60 วินาที
- **Checkpoint #2** ที่ประตูหมู่บ้านฝั่งป่า → Q001-P2 สำเร็จ

### SC-03 — เส้นทางป่า `[CANON]` · 4–6 นาที
- **Beat:** เข้าป่าลึก เสียงลำธารไกล ๆ แสงเปลี่ยน → ลางร้าย → เสียงกรีดร้องที่คุ้นเคย → Phineas **วิ่ง**
- `[IMPL]` Environmental storytelling: รอยเล็บ, ไอดำจาง ๆ, ต้นไม้ที่ตาย
- เสียงกรีด → Q001-P3 เริ่ม, **Sprint sequence** (กล้องไดนามิก, FOV กว้าง, ฝีเท้า/ลมหายใจดัง) ผู้เล่นควบคุมเองจนถึงหน้าผา
- ไม่มีศัตรูอื่น (รักษาโฟกัสอารมณ์) · `[OWNER D-015]` ถังน้ำหลุดมือระหว่างวิ่ง (ภาพเล็ก ๆ ที่บอกว่า "เควสเดิมไม่สำคัญแล้ว")

### SC-04 — วิกฤตที่หน้าผาลำธาร `[CANON]` + `[OWNER D-003]` · 2–3 นาที
1. `[OWNER D-003]` **เอเลนาใช้เวท Aethel-Water สู้หมาป่าทมิฬแล้วล้มเหลว** — ต้องเกิด *ก่อน* Phineas ถึงตัวเธอ
   - `[OWNER D-014]` ผู้เล่นวิ่งโผล่ขอบลานแล้ว**เห็นเอง** (cutscene สั้น 10–15 วิ): สายน้ำจากลำธารพุ่งใส่หมาป่า → ไอดำกลืน/ระเหยน้ำ → หมาป่าสะบัดเธอล้ม → เธอถูกต้อนจนมุม ร้องไห้
   - ความหมาย: "ทุกคนมีเวท ยกเว้นเขา — แต่แม้แต่เวทก็สู้สิ่งนี้ไม่ได้"; Phineas ไม่มีอาวุธ ไม่มีเวท `[CANON]`
2. `[IMPL]` Prompt เดียว **"วิ่งเข้าไปกอด"** (Interact — ไม่มีทางเลือกหนี)
3. Phineas เอาร่างบังเอเลนา → หมาป่ากัดหลัง → **HP = 1** + หน้าจอสีเลือดวิกฤต → ทรุด แต่ยังโอบเอเลนาไว้ `[CANON]`
- HP bar บน HUD ลดเหลือ 1 ให้เห็นชัด (ใช้ HUD ตัวเดียวที่มีให้คุ้ม)

### SC-05 — การตื่นรู้ `[CANON]` · 2–3 นาที
1. ทุกอย่างหยุดนิ่ง ดนตรีเงียบ เหลือแค่เสียง**โซ่ตรวนยักษ์ลากครูดพื้น**ก้องในหัว
2. แขนขวาปวดร้าว — camera shake, chromatic aberration, haptic
3. **รากไม้หนามสีดำ** ปะทุจากเส้นเลือด → เสียบทะลุหมาป่า → ดูดพลังชีวิต
4. หมาป่าโหยหวน ร่างแห้งเหี่ยวเป็นมัมมี่
5. **Flashback** 3–5 วิ (สายตาหมาป่า / ความหิว / มีบางสิ่งสั่งมัน) → Phineas คุกเข่าร้องลั่น
- `[IMPL]` **Interactive beat:** กดค้าง/สลับปุ่มเพื่อ "ปล่อยราก" — ล้มเหลวไม่ได้ ผลลัพธ์คงที่
- `[IMPL]` HP ฟื้นจากการดูด (1 → เต็ม) = ผู้เล่น "รู้สึก" ว่าพลังนี้ทำอะไร · Humanity ลดเบื้องหลัง (ไม่แสดง)
- ⚠️ "ใครสั่งหมาป่า" = แค่ภาพเงา/ความรู้สึก ห้ามระบุตัวตน (lore สงวนของเจ้าของ)

### SC-06 — จิตวิญญาณที่แตกสลาย (Cliffhanger) `[CANON]` · 2–3 นาที
- ไอดำพวยพุ่งจากแขนขวาที่กลายพันธุ์ → Phineas หันไปยื่นมือสั่นเทาหาเอเลนา
- `[IMPL]` **ปุ่มยื่นมือ** (ผู้เล่นกดเอง → เห็นเธอปัด → เจ็บกว่าดูเฉย ๆ)
- แววตาเอเลนาเปลี่ยน: รังเกียจ ขยะแขยง หวาดกลัว → ปัดมือ ร้องไห้ กรีดร้อง (บทพูด `[CANON]` คงตาม `06` ทุกตัวอักษร):
  > "อย่าเข้ามาใกล้ฉัน! พลังดูดวิญญาณนั่น... แกมันก็สัตว์ประหลาดเหมือนพ่อของแก! ที่ผ่านมาแกแกล้งทำเป็นคนดีเพื่อจะฆ่าฉันใช่ไหม?!"
- เธอวิ่งหนีกลับหมู่บ้าน → Phineas ยืนนิ่ง → น้ำเหลืองดำหยดลงดินก่อเป็นข้อความ:
  > "จงหนีไป... ผนึกกำลังจะแตกแล้ว"
- กล้องซูมเอาต์ขึ้นฟ้า → Fade → `S05_EndCredit`: Title + "To be continued" → Q001 ปิด, Q002 "หนีไป" แสดงเป็นชื่อเควสถัดไป (ไม่ต้องเล่นได้)
