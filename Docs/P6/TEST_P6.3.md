# TEST P6.3 — ไอคอนปุ่มตามอุปกรณ์ + BUG-604 / BUG-605

> ประเภทงาน: **UI** · หลักฐาน: ภาพหน้าจอของแต่ละจุดที่มีคำใบ้ปุ่ม (คีย์บอร์ด 1 ภาพ + จอย 1 ภาพ) · ระดับ: **BLOCKING**
> ผู้ทดสอบ: เจ้าของ (เล่นใน Unity Editor) · Backlog: B-604 · อ้างอิง: `Docs/P6/BUGS.md`

**เตรียมก่อนเริ่ม**
- เปิดฉากที่ต้องการใน `Assets/_Project/Scenes/` แล้วกด Play ได้เลย (`_Boot` ตามมาเอง) — ข้อ 1–4 ให้ **ถอดจอยออก** ก่อน
- คลิกในหน้าต่าง Game ให้ Editor รับปุ่มก่อนทุกครั้ง และเปิดหน้าต่าง Console ทิ้งไว้
- คำว่า "ไอคอนจอย" ในเอกสารนี้หมายถึงรูปแบบ (Y) / (Start) / (L) · "ไอคอนคีย์บอร์ด" หมายถึง [E] / [Esc] / [WASD]
- ปุ่มโต้ตอบบนจอยคือ **(Y)** (ปุ่มบน) ตามที่ผูกไว้ใน Input Actions · (A) คือปุ่มยืนยันในเมนู · คำใบ้กล้องบนคีย์บอร์ดตอนนี้แสดง [Mouse]
- ผ่าน = ติ๊กช่อง · ไม่ผ่าน = จดเลขข้อ + สิ่งที่เห็นจริง + ภาพหน้าจอ

## A. คีย์บอร์ด/เมาส์ ไม่ต่อจอย (ต้องเหมือนเดิมทุกอย่าง)

- [ ] **1. S00 คำใบ้ข้ามคอมิก**
  - ขั้นตอน: Title → "เริ่มเกมใหม่" → รอจนคำใบ้ข้ามขึ้น
  - คาดหวัง: ขึ้น "กด [E] ค้างไว้เพื่อข้าม" · กด E ค้างแล้วข้ามไป S01 ได้

- [ ] **2. S01 คำใบ้เดิน + คำใบ้ภารกิจ**
  - ขั้นตอน: เข้า `S01_Bedroom` รอคำใบ้แรก แล้วเดินจนคำใบ้ที่สองขึ้น
  - คาดหวัง: "[WASD] เดิน · [Mouse] กล้อง" แล้วตามด้วย "[Esc] หยุดเกม · ดูภารกิจปัจจุบัน" · แต่ละอันหายเองใน ~6 วิ

- [ ] **3. HUD ปุ่มโต้ตอบ**
  - ขั้นตอน: ใน S01 เดินเข้าใกล้ถังน้ำ / นาฬิกาพก
  - คาดหวัง: ขึ้น "[E] หยิบถังน้ำ" / "[E] ดูนาฬิกาพก" · มี [E] แค่ครั้งเดียว ไม่ซ้ำ

- [ ] **4. S04 beat ในคัตซีน**
  - ขั้นตอน: เล่น `S04_StreamCliff` จนถึง beat ทั้ง 3 (ปิดตัวเลือก "กดครั้งเดียวแทนการกดค้าง")
  - คาดหวัง: "[E] วิ่งเข้าไปกอด" → "[E] กดค้างเพื่อปล่อยราก" → "[E] ยื่นมือ" · กด/กดค้าง E แล้วผ่านทุก beat

## B. ต่อจอย (เสียบจอยแล้วเล่นด้วยจอยอย่างเดียว)

- [ ] **5. S00 คำใบ้ข้ามคอมิก**
  - ขั้นตอน: กดปุ่มจอย 1 ครั้ง → เริ่มเกมใหม่ → รอคำใบ้ข้าม → กด (Y) ค้าง
  - คาดหวัง: คำใบ้แสดงไอคอนจอย (Y) แทน [E] ข้อความที่เหลือเหมือนเดิม · กด (Y) ค้างแล้วข้ามได้

- [ ] **6. S01 คำใบ้เดิน + คำใบ้ภารกิจ**
  - ขั้นตอน: เข้า S01 ด้วยจอย รอคำใบ้ทั้งสอง
  - คาดหวัง: คำใบ้เดินเป็นไอคอนสติ๊ก (L) แทน [WASD] และกล้องเป็นไอคอนสติ๊กขวา(R) แทน [Mouse] · คำใบ้ภารกิจเป็น (Start) แทน [Esc] · ไม่มีวงเล็บเหลี่ยมของคีย์บอร์ดหลงเหลือ

- [ ] **7. HUD ปุ่มโต้ตอบ**
  - ขั้นตอน: เดินด้วยสติ๊กซ้ายเข้าใกล้ถังน้ำ แล้วกด (Y)
  - คาดหวัง: ขึ้น "(Y) หยิบถังน้ำ" · กด (Y) แล้วหยิบได้

- [ ] **8. S04 beat แบบกดและกดค้าง**
  - ขั้นตอน: เล่น S04 ด้วยจอยจนครบ 3 beat (ปิด "กดครั้งเดียวแทนการกดค้าง")
  - คาดหวัง: ทั้ง 3 beat แสดง (Y) แทน [E] · beat ที่ 2 ยังเป็น "กดค้างเพื่อปล่อยราก" และต้องกด (Y) ค้างจึงผ่าน

- [ ] **9. S04 เมื่อเปิด "กดครั้งเดียวแทนการกดค้าง"**
  - ขั้นตอน: ตั้งค่า → เปิด "กดครั้งเดียวแทนการกดค้าง" → เล่น S04 ถึง beat ที่ 2 ทำ 2 รอบ (จอย 1 รอบ, คีย์บอร์ด 1 รอบ)
  - คาดหวัง: ข้อความเป็น "กดเพื่อปล่อยราก" · ไอคอนเป็น (Y) ตอนใช้จอย และ [E] ตอนใช้คีย์บอร์ด · กดครั้งเดียวผ่าน

## C. สลับอุปกรณ์ระหว่างที่คำใบ้ยังอยู่บนจอ

- [ ] **10. สลับตอน HUD ปุ่มโต้ตอบขึ้นอยู่**
  - ขั้นตอน: ยืนข้างถังน้ำให้ "[E] หยิบถังน้ำ" ค้างอยู่ → ขยับสติ๊กซ้ายหรือกดปุ่มจอย → แล้วกด W บนคีย์บอร์ด
  - คาดหวัง: เปลี่ยนเป็น (Y) ทันทีโดยไม่ต้องเดินออกแล้วเข้าใหม่ → กลับเป็น [E] ทันทีเมื่อกดคีย์บอร์ด

- [ ] **11. สลับตอนคำใบ้ S01 ขึ้นอยู่**
  - ขั้นตอน: เข้า S01 ด้วยคีย์บอร์ด พอ "[WASD] เดิน…" ขึ้น ให้ขยับสติ๊กซ้ายภายใน 6 วิ
  - คาดหวัง: คำใบ้ที่ค้างอยู่เปลี่ยนเป็นไอคอนจอย · ไม่กะพริบ ไม่เริ่มนับเวลาใหม่จนค้างนานผิดปกติ

- [ ] **12. สลับตอน beat ใน S04 รอปุ่มอยู่**
  - ขั้นตอน: ถึง beat "กดค้างเพื่อปล่อยราก" อย่าเพิ่งกด → กดปุ่มทิศบนจอย → กด W บนคีย์บอร์ด → แล้วกดค้างให้ผ่าน
  - คาดหวัง: ไอคอนสลับ [E] → (Y) → [E] ตามอุปกรณ์ล่าสุด · การสลับไม่ทำให้ beat ผ่านเอง · กดค้างได้ทั้งสองอุปกรณ์

- [ ] **13. สลับตอนคำใบ้ข้ามคอมิกใน S00 ขึ้นอยู่**
  - ขั้นตอน: ใน S00 ขณะคำใบ้ข้ามแสดงอยู่ สลับคีย์บอร์ด → จอย → คีย์บอร์ด
  - คาดหวัง: ไอคอนในคำใบ้เปลี่ยนตามทุกครั้ง · บทบรรยายไม่สะดุดหรือข้ามบรรทัด

- [ ] **14. ขยับเมาส์อย่างเดียวต้องไม่สลับไอคอน**
  - ขั้นตอน: เล่นด้วยจอยให้ "(Y) หยิบถังน้ำ" ค้างอยู่ → ขยับเมาส์ไปมา ~5 วิ โดยไม่คลิกและไม่กดคีย์ → แล้วขยับเมาส์พร้อมกับโยกสติ๊ก
  - คาดหวัง: ยังเป็น (Y) ตลอด ไม่กะพริบสลับ [E] ↔ (Y)

- [ ] **15. ถอดจอยกลางเกม (เสริม)**
  - ขั้นตอน: ขณะไอคอนจอยแสดงอยู่ ถอดสายจอย แล้วเล่นต่อด้วยคีย์บอร์ด
  - คาดหวัง: คำใบ้กลับเป็นไอคอนคีย์บอร์ด · เกมไม่ค้าง · Console ไม่มี error

## D. BUG-604 — ซับไตเติลต้องไม่ค้างหลังกลับหน้าหลัก

- [ ] **16. กลับหน้าหลักขณะซับขึ้นอยู่**
  - ขั้นตอน: ใน S01 กด E ดูนาฬิกาพก (หรือเดินผ่านชาวบ้านใน S02) → ขณะซับยังขึ้น กด Esc → "กลับหน้าหลัก"
  - คาดหวัง: หน้า Title ไม่มีซับค้างเลยแม้แต่เฟรมเดียวหลังจอ fade เสร็จ · รอ 10 วิ ก็ไม่มีบรรทัดเก่าโผล่มา

- [ ] **17. ซับยังทำงานหลังจากนั้น**
  - ขั้นตอน: ต่อจากข้อ 16 กด "เริ่มเกมใหม่" หรือ "เล่นต่อจากจุดบันทึก" แล้วทำให้ซับขึ้นอีกครั้ง
  - คาดหวัง: บรรทัดเก่าไม่กลับมาเล่นต่อ · ซับใหม่ขึ้นและหายตามปกติ

## E. BUG-605 — อินโทรคอมิกต้องหยุดตอนเปิดเมนูหยุดเกม

- [ ] **18. บทบรรยายไม่เดินขณะหยุดเกม**
  - ขั้นตอน: เริ่มเกมใหม่ → ใน S00 จำบรรทัดที่ขึ้นอยู่ → กด Esc → รอ 15 วิ → กด "เล่นต่อ"
  - คาดหวัง: ตลอด 15 วิ บรรทัดเดิมค้างอยู่ ไม่เปลี่ยนบรรทัด ไม่โหลด S01 · พอเล่นต่อ บทบรรยายเดินต่อจากบรรทัดเดิมและครบทั้ง 4 บรรทัด

- [ ] **19. กดค้างเพื่อข้ามใช้ไม่ได้ขณะหยุดเกม**
  - ขั้นตอน: ใน S00 กด Esc → กด E ค้าง 5 วิ (ทำซ้ำด้วย (Y) บนจอยถ้าต่ออยู่) → ปล่อย → "เล่นต่อ" → กด E ค้างอีกครั้ง
  - คาดหวัง: ขณะเมนูเปิด ไม่ข้ามและไม่มีความคืบหน้าสะสม · หลังเล่นต่อ กดค้างแล้วข้ามได้ตามปกติ โดยต้องกดค้างเต็มเวลาใหม่
  - หมายเหตุ: ถ้า (A) ไปกดปุ่มในเมนูแทน ถือว่าปกติ ให้ดูแค่ว่าคอมิกไม่ถูกข้ามขณะเมนูยังเปิด

## F. Regression

- [ ] **20. BUG-602 — หยุดเกมระหว่าง beat แล้วกด E (จุดทดสอบของเจ้าของที่ค้างจาก P6.1)**
  - ขั้นตอน: S04 ถึง beat "วิ่งเข้าไปกอด" → Esc → กด E หลายครั้ง → "เล่นต่อ" → กด E · ทำซ้ำกับ beat "กดค้างเพื่อปล่อยราก" โดยกด E ค้างขณะหยุดเกม
  - คาดหวัง: ขณะเมนูเปิด beat ไม่ผ่าน คัตซีนไม่เดิน · หลังเล่นต่อ prompt ยังอยู่และไอคอนถูกต้อง กดแล้วผ่าน

- [ ] **21. BUG-602 ด้วยจอย**
  - ขั้นตอน: เหมือนข้อ 20 แต่หยุดเกมด้วย (Start) และกด (Y) ขณะเมนูเปิด
  - คาดหวัง: beat ไม่ผ่านขณะเมนูยังเปิด · หลังเล่นต่อ กด (Y) แล้วผ่าน

- [ ] **22. ตัวเลือก "ลดแสงแฟลชบนจอ"**
  - ขั้นตอน: ตั้งค่า → เปิด → เล่น S04 ช่วงแฟลชความทรงจำ → ปิดแล้วเล่นซ้ำ
  - คาดหวัง: เปิด = แฟลชจางลงชัดเจน (ประมาณ 1/4 ของปกติ) · ปิด = สว่างเท่าเดิม · สวิตช์ในหน้าตั้งค่ากดได้ทั้งเมาส์และจอย

- [ ] **23. ตัวเลือก "กดครั้งเดียวแทนการกดค้าง" ปิดแล้วกลับเป็นเดิม**
  - ขั้นตอน: เปิดตัวเลือก (ทดสอบในข้อ 9) → ปิด → เล่น S04 ถึง beat ที่ 2 → กด E สั้น ๆ 1 ครั้ง → แล้วกดค้าง
  - คาดหวัง: ข้อความกลับเป็น "กดค้างเพื่อปล่อยราก" · กดสั้นไม่ผ่าน · กดค้างผ่าน

- [ ] **24. "เล่นต่อจากจุดบันทึก" จากหน้า Title**
  - ขั้นตอน: เล่นจนเห็น "บันทึกความคืบหน้าแล้ว" (CP_01 หรือ CP_02 ใน S02) → Esc → "กลับหน้าหลัก" → "เล่นต่อจากจุดบันทึก" (ลองทั้งเมาส์และ (A))
  - คาดหวัง: โหลดกลับไปจุดบันทึกล่าสุด ภารกิจและถังน้ำในมือตรงกับตอนบันทึก · คำใบ้ปุ่มแสดงตามอุปกรณ์ที่ใช้อยู่

- [ ] **25. Console สะอาดตลอดรอบทดสอบ**
  - ขั้นตอน: หลังทำข้อ 1–24 ดูหน้าต่าง Console (เปิด Error + Exception)
  - คาดหวัง: ไม่มี error / exception แม้แต่รายการเดียว รวมถึงตอนสลับอุปกรณ์และตอนกลับหน้าหลัก
