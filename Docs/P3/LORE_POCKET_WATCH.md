# Lore Proposal — นาฬิกาพกของ Phineas (v0.1)

> เจ้าของเอกสาร: อ.รัตติกาล (Narrative Director) · ร่วม: ภูผา, นนท์, อ.ชัย · สถานะ: **[PROPOSAL] รอเจ้าของอนุมัติ (Q-016)**
> โจทย์จากเจ้าของ (D-030): ดูเป็นของเก่าธรรมดา แต่สำคัญต่อเนื้อเรื่อง · เกี่ยวกับ**ตระกูล**ของพระเอก และ**พลังที่ตื่น**
> ขอบเขตที่ทีม**ไม่แตะ**: ความจริงของพ่อ (ฆาตกรจริงไหม/ทำไม) และทิศทางของเอเลนาหลังเดโม — ยังเป็นของเจ้าของ (`02` §2)

🏢 [302 Writers' Den] อ.รัตติกาล: "ของที่ดีที่สุดในเรื่อง คือของที่ผู้เล่นเห็นตั้งแต่นาทีแรก แล้วเพิ่งเข้าใจในชั่วโมงที่สิบ — นาฬิกาที่ไม่เคยเดิน… จนกระทั่งวันที่เขาเกือบตาย"

## สิ่งที่เป็นแกนร่วม (ทุกตัวเลือกใช้)
- **รูปลักษณ์:** นาฬิกาพกทองเหลืองหมอง โซ่สั้น หน้าปัดเลขโรมัน กระจกมีรอยร้าวเล็ก ๆ — ตรงกับ concept ภาพที่ 1–2 ของเจ้าของ (ใช้แบบ**นาฬิกาพก** ไม่ใช่นาฬิกาข้อมือ เพราะ "เก่า + ธรรมดา" กว่า)
- **ไม่เคยเดิน:** เข็มหยุดนิ่งที่เวลาเดิมตลอดชีวิตของ Phineas — ชาวบ้านมองว่าเป็น "ของไร้ค่าของลูกฆาตกร" ไม่มีใครอยากแตะ
- **มี 3 เข็ม** (ชั่วโมง / นาที / วินาที) = **3 Hollows** (Inversus · Radix · Nihil) — เข็มแต่ละอันขยับเมื่อผนึกชั้นนั้นแตก → ผู้เล่นเห็น "ความคืบหน้าของคำสาป" บนวัตถุจริง ไม่ต้องมีเกจ UI
- **เสียงโซ่ในหัว** (CANON ฉากตื่นรู้) สัมพันธ์กับ**เสียงติ๊ก**ของนาฬิกา: ครั้งแรกในชีวิตที่มันเดิน คือวินาทีที่รากดำปะทุ

## ตัวเลือก
### ก) "สมอแห่งผนึก" (Seal Anchor) — นาฬิกาคือกุญแจของผนึก ⭐ แนะนำ (ร่วมกับ ค)
- ผนึกที่กักปีศาจ 3 ตนไม่ได้อยู่ในร่าง Phineas อย่างเดียว — **ครึ่งหนึ่งถูกผูกไว้กับนาฬิกา** เวลาที่หยุดนิ่ง = ผนึกที่ยังสมบูรณ์
- ราคาของพลัง (Pillar "พลังมีราคา"): ทุกครั้งที่ใช้พลัง Hollow มาก ๆ เข็มวินาทีจะสั่น → เป็นสัญญาณภาพของ Humanity/ผนึก (D-002 ยังไม่โชว์ตัวเลข — นาฬิกาเป็น feedback แบบไม่ใช่ HUD ได้ในอนาคต)
- ตระกูล: นาฬิกาทำจากเวท **Aeterna** (กาล/มิติ — **CANON** ว่าเป็นเวทระดับราชวงศ์) → แปลว่าใครสักคนในสายเลือดของ Phineas เคยใช้ Aeterna ได้
- **ปมใหญ่ที่เปิดไว้:** ราชวงศ์มีเวท ≥ 2 แขนง (CANON) แต่ Phineas เป็น 0 — ถ้าเขามีสายเลือดสูงส่งจริง "ช่องเวท" ของเขาไม่ได้ว่าง แต่**ถูกปีศาจจับจองไว้ทั้งหมด** ("Hollow" = ช่องที่ถูกเติมด้วยสิ่งอื่น)
- ข้อดี: ผูกทั้ง 3 ฟอร์ม + ตระกูล + ฉากตื่นรู้เข้าด้วยกันในวัตถุเดียว · ข้อเสีย: ทำให้ "Phineas มีสายเลือดสูงส่ง" เป็นเรื่องใหญ่ที่ต้องรับผิดชอบต่อในเกมเต็ม

### ข) "มรดกผู้เฝ้าผนึก" (Wardens' Heirloom) — ตระกูลผู้กักปีศาจ
- ตระกูลของ Phineas ไม่ใช่เชื้อพระวงศ์ แต่เป็น **ตระกูลผู้เฝ้าผนึก** ที่สืบทอดหน้าที่กักสิ่งชั่วร้ายมาหลายรุ่น นาฬิกาคือเครื่องหมายประจำตระกูล (มีตราสลักใต้ฝา ที่ผู้เล่นเห็นแต่อ่านไม่ออก)
- พลังที่ตื่น = ปีศาจที่ตระกูลกักไว้ "ส่งต่อ" มาถึงรุ่นเขา
- ข้อดี: ไม่ชนกับราชวงศ์ เล่าง่าย · ข้อเสีย: ใกล้เคียงสูตรนิยายทั่วไป (ภาชนะ/ผู้เฝ้า) และเสี่ยงตอบคำถามเรื่องพ่อแทนเจ้าของ (ทีมจะไม่ระบุว่าพ่อเป็นผู้เฝ้าหรือไม่)

### ค) "นาฬิกานับถอยหลัง" (The Countdown) — เวลาที่เหลือก่อนผนึกแตก
- นาฬิกาไม่ได้หยุด — มัน**เดินถอยหลังช้ามากจนมองไม่เห็น** และกำลังเข้าใกล้ 12:00 → เชื่อมกับข้อความ CANON ของพ่อ "จงหนีไป... ผนึกกำลังจะแตกแล้ว"
- ฉากจบเดโม: หลังข้อความน้ำเหลืองดำ เข็มวินาทีกระตุกหนึ่งครั้ง — **เสียงติ๊กเดียวในความเงียบ** ก่อนกล้องซูมเอาต์ (Cliffhanger ชั้นที่สอง)
- ข้อดี: สร้างแรงกดดันและ "นาฬิกาเกม" ให้เกมเต็ม (Act 2–3) · ข้อเสีย: ถ้าใช้เดี่ยว ๆ จะบางเรื่องตระกูล

**ทีมแนะนำ ก + ค:** นาฬิกาเป็น *สมอผนึกจากเวท Aeterna ของบรรพบุรุษ* ที่ *เดินถอยหลังเข้าหาการแตกของผนึก* — ตระกูล + พลัง + แรงกดดันของเรื่อง ครบในของชิ้นเดียว

## คำถามถึงเจ้าของ (Q-016)
1. เลือก ก / ข / ค หรือผสม (ทีมแนะนำ **ก + ค**)
2. ถ้าเลือก ก: ยอมให้ "Phineas มีสายเลือด Aeterna" เป็นความจริงของโลกไหม — หรือให้คลุมเครือไว้ (default: **คลุมเครือ** จนกว่าเจ้าของจะตัดสินในเกมเต็ม)
3. นาฬิกาเป็นของจาก**พ่อ**หรือจาก**แม่/ฝั่งอื่นของตระกูล** — ทีมไม่เดา (เกี่ยวกับความจริงของพ่อ = ของเจ้าของ) · default ระหว่างรอ: "ได้มาตั้งแต่จำความได้" ไม่ระบุว่าใครให้
